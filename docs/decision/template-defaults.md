# テンプレート既定値レジスタ（Template Defaults Register）

**目的**：本テンプレートの文書（指針書、ADR、質問票、決定木、レビューキット）に現れる数値のうち、**外部出典で裏付けられない組織閾値**と、**本テンプレートの試験で確定すべき計測値**を一箇所に集め、根拠・影響範囲・調整方法・見直し契機を固定する。各文書は値の横に「既定値（例示値）: … 調整: docs/decision/template-defaults.md#既定値レジスタ（TD-NN）」または「計測で確定: …（M-NN）」と書き、本レジスタがその正本である。

**位置づけ**：

- 「既定値（例示値）」は、テンプレートをそのまま使ったときに効く値であり、採用組織が `service.yaml`、Construct props、または ADR 改訂で調整することを前提とする。外部出典が示すのは方向性（例：Builders' Library の負荷制御原則、AWS quota の上限）であり、数値自体は設計判断である。
- 「計測で確定」は、テンプレート付属の試験・ツール（`tests/performance/order-api.k6.js`、`pnpm power-tuning`、`pnpm cost-model`、`tests/resiliency`、CloudWatch metrics）で得る値であり、計測前に数値を書かない。計測後は ADR の Evidence 節と本レジスタの「現在の値」列を同時に更新する。
- 外部事実で公式ドキュメントに記載がないものは、各文書に「公式ドキュメントに記載なし（確認日、URL）」と書き、本レジスタには載せない（監査記録は `docs/review/evidence-register.md`）。

**2026-10-17/18 sandbox 実測の要約**（「現在の値」列の出典）：ap-northeast-1 の `paas-sandbox-cell-01` に 4 stacks をデプロイ（専用 bootstrap qualifier `paas`、1 回の full deploy ≈ 7 分）、`tests/integration`（3 件）と `tests/tenant-isolation`（3 件）が 2 回 pass、新規アカウントの Lambda 同時実行 quota は 10、API Gateway の requestId は `=` を含む、`pnpm diagrams:deployed` で cdk2d2 の配置図を生成。負荷試験（k6、steady 30 RPS + overload 150 RPS、`tests/performance/results/order-api-2026-10-18.*`）と Lambda Power Tuning（ListOrders、`tools/power-tuning/results/*-1792277941831.json`）を実施。cost-model の試算、Web Functions ベンチマーク、1,000 RPS 級の負荷は未実施。**quota 10 の sandbox で得た値は、production（quota 増枠後）の値ではなく「テンプレートの負荷制御が機能すること」の確認値**として読む。
