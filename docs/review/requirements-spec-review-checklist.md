# 要求仕様書レビューチェックリスト

対象：マイクロサービス / PaaS の要求仕様書（workload profile を含む）。
目的：アーキテクチャ判断（`docs/decision/` の質問票・決定木）に必要な入力が揃っているかを確認し、欠落を実装前に埋める。
判定：各項目を「合格 / 指摘 / 対象外（理由）」で記録し、`docs/review/README.md` の findings 表へ転記する。
根拠：「根拠」列の `E-NN` は [evidence-register.md](./evidence-register.md) を参照。出典で裏付けられない閾値は「既定値（例示値）」とし、`docs/decision/template-defaults.md` の `TD-NN` を併記する。

指針 §1 と「実装ロードマップ Phase 0」は、想定 RPS、tenant 数、burst、payload、SLO、データ分類を **1枚の workload profile** に記録することを要求している。本チェックリストはその1枚に何が必要かを分解したものである。
