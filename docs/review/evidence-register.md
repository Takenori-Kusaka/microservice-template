# Evidence Register（根拠台帳）

`docs/review/` と `docs/decision/` の全主張の出典一覧。各ファイルの「根拠」列は本台帳の ID（`E-NN`）を参照する。
確認日が `指針引用` のものは `docs/architecture/guidelines-outline.md` の References（`[^N]`）を再利用したもので、本台帳作成時には再取得していない。再取得が必要な場合は該当 URL を開いて確認日を更新する。
数値（quota、料金、上限）は確認日時点の公開ドキュメントの値であり、ADR へ転記する際は必ず再確認する。

## 運用ルール

- 新しい主張を追加するときは、先に本台帳へ行を追加し、確認日を記録する。
- 出典で確認できなかった主張は、各ファイルで「既定値（例示値）: … 調整: TD-NN」「計測で確定: … M-NN」（正本は `docs/decision/template-defaults.md`）または「公式ドキュメントに記載なし（確認日、URL）」と明記し、事実ではなく仮定として書く。旧「要検証」タグは第 2 回監査（2026-10-18）で全廃した。
- 四半期の architecture/conformance review（指針 §19）で、確認日が 12 か月を超えた行を再確認する。
